# Photos

Drop your photographs here with these names. A missing photo simply shows a soft placeholder.

| File | Where it appears | Suggested shape |
|---|---|---|
| `cover.jpg` | Hero and first gallery view | Portrait, 4:5, at least 1600 px tall |
| `spread.jpg` | Gallery: an open page spread | Landscape, 16:10, at least 2000 px wide |
| `in-hand.jpg` | Gallery: the book in a hand, on a street | Landscape, 16:10 |
| `detail.jpg` | Gallery: binding, paper, texture | Landscape, 16:10 |
| `back.jpg` | Gallery: back cover | Landscape, 16:10 |
| `author.jpg` | About the author | Square, at least 600 px |

Export as JPEG at about 80 percent quality and keep each file under 400 KB so the page stays fast.
After the cover exists, uncomment the `og:image` line in `index.html` so links shared on social media show it.
