# Explore Warsaw

Resources and prompts for curating expat-friendly weekend events in Warsaw.

## Contents

| File | Description |
|------|-------------|
| [`prompts/weekend-events-prompt.md`](prompts/weekend-events-prompt.md) | Claude prompt for finding & formatting upcoming Warsaw weekend events as Instagram Reels captions |

## How to use

1. Open the prompt file.
2. Paste it into Claude (or any AI assistant).
3. Claude will search the specified website for the upcoming weekend's events, filter for expat-friendly (English / language-neutral) ones, and return 4 formatted Instagram Reels captions.
